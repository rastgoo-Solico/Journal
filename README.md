# داشبورد مالی — Streamlit

نسخهٔ اصلی و قابل‌استقرار برنامه **Streamlit** است و همان ساختار دادهٔ `data.json` و ذخیره‌سازی GitHub کد اولیه را حفظ می‌کند. PostgreSQL برای این نسخه استفاده نمی‌شود.

## اجرای محلی

```bash
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

فایل `app.py` نیز به همان برنامه اشاره می‌کند و می‌تواند به‌عنوان Entry point انتخاب شود.

## استقرار روی Streamlit Community Cloud

1. فایل‌های پروژه را روی GitHub قرار دهید.
2. در Streamlit Cloud گزینهٔ **New app** و سپس مخزن و شاخهٔ موردنظر را انتخاب کنید.
3. Main file path را `streamlit_app.py` قرار دهید.
4. در **Settings → Secrets** سه مقدار زیر را مطابق نسخهٔ قبلی وارد کنید:

```toml
APP_PASSWORD = "your-password"
GITHUB_TOKEN = "your-github-token"
GITHUB_REPO = "owner/repository"
```

5. برنامه را Deploy کنید. فایل `requirements.txt` وابستگی‌های Python را نصب می‌کند.

> رمز واقعی، توکن GitHub و فایل پشتیبان شخصی را در مخزن عمومی commit نکنید. نمونهٔ کلیدها در `.streamlit/secrets.example.toml` است.

## سازگاری داده و ذخیره‌سازی

- ورود با همان `APP_PASSWORD` و توکن query parameter به نام `auth` انجام می‌شود.
- داده با همان کلیدهای `assets`، `usd_rates`، `gold_funds` و `settings` خوانده می‌شود.
- Migration پشتیبان‌های قدیمی شامل `journals` و `usd_rate` حفظ شده است.
- ذخیره محلی در `data.json` و ذخیره راه‌دور در مسیر `data.json` مخزن GitHub انجام می‌شود.
- محتوای GitHub همچنان **gzip + base64** است و SHA و `last_saved` هنگام ذخیره بررسی می‌شوند.
- دانلود و بازیابی فایل JSON در پنل راست باقی مانده است.
- کلید جدید `synthetic_pairs` و تنظیمات `auto_theme`، `day_start`، `night_start` و `nav_order` بدون حذف داده‌های قبلی اضافه می‌شوند.

## تحلیل‌های حفظ‌شده و قابلیت‌های جدید

- هر دارایی صفحهٔ مستقل با ارزش کل، قیمت واحد ریالی/دلاری، نمودار ارزش کل و نمودار نرمال‌شدهٔ قیمت واحد/دلار دارد.
- هر صندوق طلا تحلیل معادل دلاری، گرم طلا در واحد، واحد لازم برای یک انس، تله دلار، سیگنال انس و ماشین‌حساب آربیتراژ دارد.
- تاریخچهٔ رکوردها و نرخ‌ها قابل ویرایش و حذف است.
- صفحهٔ **جفت ارز مصنوعی** هر دو ابزار دارای تاریخچه را به یک نسبت تبدیل می‌کند؛ قیمت دارایی دلاری با نرخ همان تاریخ به ریال تبدیل می‌شود.
- ترتیب سربرگ‌ها، فونت و آیکون‌ها از پنل راست قابل تغییر است.
- حالت روز/شب می‌تواند دستی یا خودکار بر اساس ساعت تهران باشد؛ بازهٔ عبور از نیمه‌شب نیز پشتیبانی می‌شود.
